# Agile STLC & Defect Management Simulation (Manual Testing & Management)

Managed the end-to-end Software Testing Life Cycle (STLC) for a simulated web platform within an Agile/Scrum framework[cite: 1].

## Overview
This project simulates real-world Quality Assurance workflows in an Agile team environment, focusing on test planning, manual execution, and bug tracking.

## Key Responsibilities & Features
- Created comprehensive test plans and designed detailed Test Cases based on business requirements.
- Executed manual Functional, Integration, and User Acceptance Testing (UAT) to identify UI/UX and functional issues accurately[cite: 1].
- Documented, reported, and tracked software defects using **Jira**, providing clear steps to reproduce, expected vs. actual results, and attachments for developers[cite: 1].

## Tech & Tools
- **Methodology:** Agile / Scrum, STLC[cite: 1]
- **Bug Tracking & Management:** Jira[cite: 1]
- **Testing Types:** Functional Testing, Integration Testing, User Acceptance Testing (UAT)[cite: 1]
